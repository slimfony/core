# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful and constructive, assume good faith, keep to the technical topic, and do not harass or demean anyone. Harassment, personal attacks, and publishing other people's private information are not acceptable.

Report a violation privately to the maintainers through GitHub: a private security advisory on this repository ("Report a vulnerability" on the Security tab) reaches them without being public. The maintainers will look into every report, keep it confidential, and decide what to do, from a reminder to a ban from the project.
